# SuperTrade Frontend Documentation

## Architecture
- React.js SPA
- Axios for API calls
- Chart.js for charts
- Modular folder structure (see src/)

## Pages
- Signup, Login, Dashboard, Stocks, Stock Details, Portfolio, SuperBundles, etc.

## Components
- Reusable UI components (forms, tables, charts, etc.)

## Services
- API service layer using Axios

## How to Run
1. Install dependencies: `npm install`
2. Start dev server: `npm start`
